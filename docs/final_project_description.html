System Architecture

2.1 System Overview

The system uses a distributed processing architecture with all devices on the same Wi-Fi network (SANJEEVI). A Laptop runs the brain (YOLOv8, decision engine, sensor fusion), a Raspberry Pi 5 streams camera video over UDP, and two ESP32 units manage real-time motor control (via 2× TB6612FNG for 4 motors) and ultrasonic sensing.

3.3 ESP32 #1 — Motor Controller

⚡

Motor Controller Specs

WiFi Station mode (SSID: SANJEEVI). Web UI on :8080. UDP :9000 (commands), :9001 (status broadcast), :9002 (ultrasonic receive). 2× TB6612FNG for 4 motors. Brownout detection disabled. 500ms command timeout. WiFi auto-reconnect every 5s.

3.4 ESP32 #2 — Ultrasonic Sensor

📡

Ultrasonic Specs

HC-SR04 (2–400cm). Reads every 200ms. Sends via HTTP GET to ESP32 #1 (/distance?value=XX) or UDP :9002 (ULTRA:25.50). TRIG=GPIO21, ECHO=GPIO18.

Setup & Deployment

🖥️

Hardware

Pi 5, ESP32 ×2, Pi Camera v2 / USB Webcam, HC-SR04, GPS USB, 2× TB6612FNG, 4× DC motors, 7.4V LiPo

📦

Software

Python 3.8+ (laptop), pip, PlatformIO (ESP32), OpenCV, YOLOv8, Raspberry Pi OS (Pi 5)

Quick Setup (Laptop)

Batch
:: On laptop — install dependencies & run
pip install -r requirements.txt
python robot_car_v2_modern.py

ESP32 Flashing Notes

  • Configure Wi-Fi credentials: SSID: SANJEEVI, password, target laptop IP
  • ESP32 #1: Flash esp32_motor_controller.ino — ports :9000/:9001/:9002
  • ESP32 #2: Flash esp32_ultrasonic.ino — port :9002
  • Critical: Disable brownout detection on ESP32 #1 to prevent WiFi dropout during motor spinup
  • ESP32 #1 auto-reconnects WiFi every 5s if connection lost

Pi 5 Setup

  • Install Raspberry Pi OS (desktop or lite)
  • Install Python, OpenCV, numpy
  • Enable Camera interface (raspi-config)
  • Run: python pi_camera_v2.py
  • Set static IP or DHCP reservation

Startup Sequence

  1. Power on ESP32 boards (wait ~10s for WiFi to SANJEEVI)
  2. Power on Pi 5 → auto-starts pi_camera_v2.py
  3. On laptop: python robot_car_v2_modern.py
  4. Wait for "Connected" confirmation in terminal
  5. Use arrow keys or gamepad for manual control
  6. Switch to autonomous mode via Telegram /mode or key press

Pi 5 Headless Setup

Refer to jetson_nano_headless_inst.md for headless configuration guidance:

  • Enable SSH, configure Wi-Fi, set static IP
  • Enable Camera interface (raspi-config)
  • Auto-start camera script via systemd or cron
