## 🎓 Learning Path

### Beginner Track (30 minutes)

```
1. QUICKSTART.md (5 min)
   └─→ Set up and run bot

2. /start command (2 min)
   └─→ Open bot in Telegram

3. /control command (3 min)
   └─→ Test joystick controls

4. /video command (2 min)
   └─→ See live camera feed

5. /gps command (2 min)
   └─→ View location

6. telegram_bot_cmnds.md (10 min)
   └─→ Learn essential commands

7. /autonomous command (2 min)
   └─→ Try AI mode

8. /help command (5 min)
   └─→ Read tutorials
```

**Total:** 30 minutes to proficiency

---

### Intermediate Track (1 hour)

```
1. README.md (15 min)
   └─→ Understand all features

2. FEATURES.md (10 min)
   └─→ See feature demonstrations

3. Create mission (10 min)
   └─→ Practice waypoint planning

4. Review telemetry (5 min)
   └─→ Understand metrics

5. Test voice commands (5 min)
   └─→ Try hands-free control

6. Configure settings (10 min)
   └─→ Customize bot behavior

7. Review alerts (5 min)
   └─→ Understand safety systems
```

**Total:** 1 hour to mastery
